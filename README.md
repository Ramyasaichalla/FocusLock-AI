# 🔒 FocusLock AI

> An AI-powered study focus planner that helps students stay focused during coding and study sessions.

## 🎯 Problem

Students often lose focus while studying or coding because of distracting websites and social media.

FocusLock AI provides a simple focused study environment where students can:

- Enter their study goal
- Choose a focus duration
- Get an AI-generated study plan
- Follow a focus timer
- See useful resources and common distractions
- Complete a structured focus session

## 🤖 AI Integration

FocusLock AI uses the **Gemma open-weight AI model** to generate personalized study plans based on the user's goal and available study time.

The AI generates:

- A practical study approach
- Specific tasks to complete
- Useful learning resources

This makes the project an example of how open AI models can be used to build useful tools for everyday problems.

## ✨ Features

- 🤖 AI-generated focus plans
- ⏱️ Custom focus timer
- ⏸️ Pause and resume
- 🛑 Stop session
- 🔒 Focus environment
- 📚 Allowed study resources
- 🚫 Common distractions
- 🎉 Session completion notification
